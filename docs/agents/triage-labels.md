# Triage Labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer review needed |
| `needs-info` | `needs-info` | Waiting for reporter |
| `ready-for-agent` | `ready-for-agent` | Ready for agent work |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, use its tracker label.
