单请求基线的测量草案

复用现有双机自运行入口和 Main /generate 路径。 固定 GLM-5.2 权重、量化、TP16、Graph、NUMA 和容量配置。 保持真实并发为 1；每个请求等全部 free_ack 后再开始下一个。

场景 输入与实际命中 需要回答的问题
冷请求 4096 token，命中 0；另留 128-token 短输入参考 没有复用时的首 token、生成及收尾成本
部分命中 5120 token，命中前 4096 token 恢复与后缀计算的时间
完全命中 4096 token，实际复用 3968 token 恢复后重算最后一页的时间

完全命中沿用阶段 0 的最后一页重算规则。 长生成用实际 128 输出 token 的独立负载；自然 EOS 短输出单列。 短输出不能记为 128-token decode 覆盖。

计时必须注明观察点。 现有 Main 只支持非流式请求，返回前还要完成 admit 和 free。 客户端单次 HTTP 总耗时包含这段收尾。 现有 meta_info.e2e_latency 来自 D 后端，计时边界不同。

指标 计划口径
后端 TTFT D 请求进入至首次输出可用，标明后端观察点
ITL 同一观察点相邻输出 token 的时间差；保存原始样本
TPOT 首次输出至结束的平均后续 token 时间，单独报告
后端生成耗时 保存 D 返回的 e2e_latency 与实际输出长度
Main 完整耗时 客户端发出请求至完整响应接收完成
Main 收尾 后端结果到齐至保存、释放结束，使用 Main 本地时钟

当前非流式内部默认每 50 token 刷新一次输出。 已有 SGLANG_FORCE_STREAM_INTERVAL=1 可用于首 token 测量。 --enable-metrics 可返回 first_token_latency 等字段。 后端 TTFT 复用这套观察点。

现有 ITL 指标只保留有限桶、count 和 sum。 原始逐 token 样本需新增可关闭的 Ascend 采样。 建议读取已有 prebuilt/decode 完成时间，记录 CPU 结果就绪间隔。 这类样本与 tokenizer 观察点分别标注，不冒充客户端流式 ITL。

实施时核对首次输出、批次粒度及样本数量。 有限桶直方图不能替代原始 ITL 样本；缺项明确标为缺失。

每组比较使用相同采样配置，并记录采样带来的 IPC 条件。 各进程使用本地单调时钟计算区间，跨机时间戳不直接相减。

K1 完整共享要交付什么

数据 阶段 0 副本 K1 默认副本 必须验证的行为
P/D alive 主 KV 每侧 16 每侧 8 每组 2 rank 共享物理内容，分工写、完整读
P alive Index K 16 1 指定 writer 保存；保存结束前保护来源
prefix 主 KV 16 1 只保存一份，fill 覆盖必要 alive 副本
prefix Index K 16 1 只保存一份，恢复到各 rank 的原生 HBM

单份 prefix 的 load_back 采用 rank 0 读取后广播。 三类单份区域的副本数独立于 alive 主 KV 的共享组数。 8 个 alive 主 KV 副本不会各自附带一份 Index K 和 prefix。 P alive Index K、prefix 主 KV、prefix Index K 在 P 侧各只有一份。 原生 HBM Index K 继续满足各 rank 的计算和 P→D 交接需要。 D 生成的 Index K 仍只留 HBM，不增加 DRAM 区域。

组成员、owner、writer 和 reader 分开表达。 四类副本数分别注册、分别算容量和描述符。 SR 分片仍对应所有 worker，不随副本数减为 8 或 1。

NUMA 先分配，再按配置生成共享组。 默认每节点两个 rank，显式映射使用全部目标 NUMA 节点。 实现支持规划器已有的可变组大小，不能写死相邻双 rank。 请求 NUMA、物理贡献和已验证物理页落点分别报告。

基础同步属于 K1 正确性：本步 KV 本地供给、历史 KV 完整发布。 所有 readers/writers 完成后才能释放和复用。 保留 ADR 0001 的安全发布原则；采用保守同层完成方案作为起点。 selected 并行、跨层提前写回及 3% 性能门槛留给后续性能工作。

K1 继续沿用串行、单 chunk、layer-first 和 alive 整槽后端。 远端 prefix、page-first、真实并发和 alive 页分配各属后续阶段。

第 2 票保留阶段 0 的三类私有区域及原生 HBM Index K 交接。 prefix 保存、load_back 和命中恢复继续运行。 fill 写入共享 alive 时按组分工，避免多个 rank 重复写同一目标。 admit 从对应共享 alive 副本保存到各 rank 的私有 prefix。 本票验收同时覆盖冷请求与 B/C 命中，不能只测关闭 prefix 的配置。

第 3 票把三类区域从各 16 份改为各 1 份。 所有需要读取的 rank 都取得这份物理数据的有效映射。 过渡读取方式为各 rank 读取同一份 prefix，恢复各自的原生 HBM。 保存和命中在本票均须通过；单份源不能由隐藏的私有 DRAM 副本替代。

第 4 票把该读取方式改为 rank 0 读一次再广播。 这使广播切片独立可验收，同时保持此前的 prefix 功能。

第 3 票达到四类存储副本目标，第 4 票完成 K1 的单读广播要求。 切片 5 复用已有 full-acceptance，不把前几片的正确性检查推迟到最后。
