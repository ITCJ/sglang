## 5 票 13：K2-M1 观测模式（行为不变）

**目标**：在工程分支加一个验收入口的子模式，开关控制，记下第 3 组测量要的每步分解和第 2 组离线分析要的页集合；同时把工程里残留的验收探针、人工延迟、证据输出逻辑清理掉，统一到这个模式里；并入票 10 的三项遗留。

**改动**

- 每步（每请求）：T_step 分解为 indexer、resolve / 热缓存管理、miss IO（按源：P 远端、D 本地、副本区）、控制 tick 等待、集合通信等待、attention 与 MoE 计算；每层的命中数 / 缺失数 / 缺失字节；选中 token 折成页号后的页集合，按每页记（页号, 命中 / 缺失, 缺失来源）并带请求的 (机器, attn group 或 NUMA)，票 19 的 (页, 读者 NUMA) miss 计数从这里来（可抽样，默认每步全记、离线压缩；2026-11-03 补）；producer 层之后各共享层的选择是否与 producer 层相同。
- 每 op：op1 / op2 / op3 / write_through / 远端写的提交、库完成、ack、publish、释放时间戳（沿用票 11 的结构化日志），按分片与按源的字节计数（沿用票 08 的计数）。
- 每请求：TTFT 分解（route、reserve、load_back、prefill、handoff、三条件齐）、T_tail、T_free、步数与停止边界。

## 7 票 15：K2-C1 并发最小形式（阶段 3a 的第一步）

**目标**：去掉 main router 的串行门，多个请求同时在途；仍足额 reserve；队列、cancel、代号；P、D 的协调者在每个 tick 处理多请求。

**改动**

- main router：route 不再等上一请求 admit 与 free_ack；reserve 失败进 FIFO 队列（不拒绝），释放后出队；cancel 消息与回退顺序；请求与 op 带代号，过期回执丢弃。
- SR_P / SR_D 协调者：每 tick 处理多请求的下发与汇总；draining 竞态（free_ack 与新分配）；读者计数跨请求。
- P：prefill 仍一次一个（串行 prefill），和 D 的 decode 并行；D：连续批处理，槽位数内的并发（U4 的 16）。
- D 每步顺序：多请求一批内，写回仍排在本层 all-reduce 之前（票 06 的规则按批）。

**不变**：足额 reserve；单 chunk；双写与页粒度；副本数；fail-stop；M30 的结束顺序。

**验收与证据**：并发 1 / 4 / 16 下 A / B / C / E 与 V1–V10（按并发改写）全过；每次释放后账本等式成立；队列顺序与出队时机；cancel 在 prefill 中、decode 中各一例；代号负测试（延迟回执被丢弃）；fail-stop 下全部请求清理干净；观测模式记并发下的每步分解（第一组争带宽的数，不设门槛）。

**风险**：多请求下的集合通信次序；队列与 fail-stop 的交互。

## 8 票 16：K2-C3 多 attn group

**目标**：P、D 各启若干 attention TP 组（t = 2 主、4 副），MoE 仍跨 16 卡；记账、注册、路由、prefix 操作都按组。

**改动**

- 启动：attention DP > 1 的配置；每组自己的 alive 区域（主 KV、D 侧）放在本组所在 NUMA；t = 2 时每组一个 NUMA、R = 1，t = 4 时跨两个 NUMA、R = 2（C62 的 R = ceil(t ÷ s)，s = 2）；注册按组上报。
- 记账键 (机器, attn group)（C64）：候选集合从一个变成列表；route 选 P 组与 D 组（本票按轮转或按在途数，带宽记账在票 17）；页表与描述符带组。
- 协调者：默认每组一个 SR 协调者（在该组的 scheduler 进程），main router 对多个协调者；prefix 池机器级共享，段归属仍按 NUMA，跨组的 prefix 操作由段 owner 所在组的分片执行；备选为机器级一个协调者进程（M18），本票定一个并写明理由。
- Index K 传输按组对（P 组 → D 组）；双写目标 = 选定的 D 组区域；跨组 prefix 命中（组 i 算的 prompt 被组 j 的请求命中）。

**不变**：并发规则（15）；双写；页粒度；prefix 单份交错；fail-stop。

**验收与证据**：t = 2 与 t = 4（HBM 允许时）下并发 A / B / C / E 全过；每组注册 = 映射 = 账本；跨组命中正确；每组清理与重启；Index K 按组到达；观测模式按组记每步分解。

**风险**：SGLang 对该模型 DP attention 的支持与我们钩子的时序；协调者数量的选择；t = 4 下每卡 HBM 余量（Index K 与热缓存复制 t 份）。

## 9 票 17：K2-S1 带宽记账与准入

## 10 票 18：K2-S0 页粒度 alive（三件套，行为不变）
