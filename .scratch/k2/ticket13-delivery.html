正常执行路径与所有权

RouterConfig.observe=false 时不创建 Observation、页计数 Tensor、profiler 或 JSONL。 原有 prefix 正确性校验由 verify_prefix 独立控制。 新增 Python 开关判断保留；实际开销以同配置开关对照报告为准。

开启后，每个 Main/worker 单独写 observe/<role>-rankNN-PID.jsonl。 Main 继续持有 Router 账本，SR 继续在既有有序 tick 执行状态迁移。 executor 在线程内调用实际 SDK batch / wait，分别记录库完成与 tick 看到完成。 新增观测消息使用原有通道；没有新增 collective 或网络线程状态迁移。

图内只操作固定 Tensor，从实际有效选择、命中 mask 与 current-device supply 后的 IO mask 累计每页计数。每次 forward 在既有完成事件前保存独立快照，完成后才转到 CPU。 不逐层同步，不用 Python hook 用时冒充设备时间。

producer 比较有序有效 token 选择；共享层自己的命中、IO 计数仍独立保存。 不对齐 prompt 引起一逻辑页跨两张 D 物理页时，分别保留源计数与位置。

设备 profiler 从 capture 前一直保持到正常阶段结束。捕获的 MSTX 语义范围随图重放， 动态外围范围关联 forward_id；实际工具链是否保留两次独立范围，由无模型 gate 检查。 本机未证明此能力。旧 msprof 可能合并 replay 记录，gate 缺数据即失败。

测试阶段空闲后，通过原有 tick 停止 profiler、导出并 flush。 这用于正常测试阶段收集；进程仍由既有父进程清理路径结束。 它不参与 free/所有权，不是逐 rank shutdown 释放回执。

数据与时间口径

数据 实现口径
页 内容 hash / 生成页身份、逻辑与物理位置、源主机/NUMA/副本组；同页可部分 hit、多源
缓存 miss selected = hit + miss；miss = IO miss + current supply
实际字节 页 IO 与原 source counter 核账；G2G CopyBlock 与 receipt 核账，再与票09功能 receipt 对比
本地策略 实际 hot_cache_tokens；replace_selected，不冒充 LRU 或三档缓存已接入
T_step D 当前推进 tick 入口到原生结果处理后的 token_ready
T_gap / TBT 保留有符号 gap 与真实相邻 token_ready 差，允许 overlap
TTFT Main 收到 HTTP 请求到收到 D 首 token 就绪消息，含该观测消息延迟
TTFT 阶段 Main route/alloc/load_back/dispatch 往返；P prefill→handoff；D handoff→三条件→首输出，各用本地时钟
tail/free Main finished→最后 free_ack；每侧 free 发送→对应 free_ack
op enqueue、executor_start、SDK submit/return/wait、poll、shard、ack、publish、source_release、credit_return 分开
停止 prefill/decode 提交数、结果完成数、丢弃输出数、prebuilt、输出数、停止原因与末写位置

设备区间按 stream-bound MSTX 范围解释。主机与设备通过 profiler 内的 host mark 做对齐并报告 anchor 不确定度；P/D 主机时钟不直接相减。

主流 hit 等待和后续 miss 等待分开；miss 只记等待区间内实际 P/D 拷贝子范围。 observer IO 单列，侧流 busy 与暴露时间分开。

关键 rank 按完整 T_step 选择，所有分类取该 rank 的整条时间线，不相加各分类的跨 rank 最大值。 未覆盖的主机排队、采样和输出处理进入明确标注的 residual。 缺 rank、缺层、缺输出步计时、缺 HCCL 任务、缺/错核账都会产生 incomplete。

NUMA 来自配置与注册，不能解释成物理驻留已验证。 当前没有 replica 读与远端写，记录 not_applicable。 独立 B=k/2k/4k 日志由用户并行分支提供；本地不制造三档容量数据。
