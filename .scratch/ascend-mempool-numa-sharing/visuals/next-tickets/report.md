## B 同一份 NUMA 分配，切换池数量

以下是单台主机的示意分配。

| 已分配的成员 | share=0 | share=1 |
| --- | --- | --- |
| rank0、rank1 → NUMA0 | 两个独立池 | 一个共享池 |
| rank0 → NUMA0；rank1 → NUMA2 | 两个独立池 | 两个单成员池 |
| rank0–3 → NUMA0 | 四个独立池 | 一个共享池 |
| rank0、1 → NUMA0；rank2、3 → NUMA2 | 四个独立池 | 两个共享池 |

每个共享池只分配一份完整 KV。
各 rank 保留自己的映射，直接写互斥分片。
每个 rank 仍读取完整 selected KV 到自己的 HBM。
池的 owner 无需代理其他 rank 的数据拷贝。

新部署模板显式开启共享，默认两 rank / NUMA。
旧启动未设置开关时，保持独立池行为。
配置在启动时确定，变更后重启生效。
这里的可调节指启动配置，在线迁移另行设计。

拟新增变量为 `SGLANG_NPU_MEMPOOL_SHARE=0|1`。
这是待实现的接口设计，目前不能直接使用。
现有 NUMA 节点列表继续按 rank 轮转。
自定义逐 rank 分配另设明确输入，避免改变旧含义。
