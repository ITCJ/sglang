A

正常执行路径

每组 BM 会话包含两个 P 成员和两个 D 成员。 P owner 分配共享主 KV 和自己的附属区域。 另一 P 成员只分配自己的 Index K、prefix 和配对探针。 每个 D 成员分配自己的主 KV。

prefill_groups 指定分组，首成员为 owner。 prefill_write_assignment 控制连续分块或轮转。 每次 forward 的主 KV 计数与 Index K 计数分别核对。 因此一个 rank 可以没有后缀主 KV 写入，仍须完成其 Index K 写入。

prefix fill 只写本成员负责的主 KV 页，并恢复全部私有 Index K。 admit 从共享主 KV 和本 rank 的 Index K 保存到私有 prefix。 SR 合并同组页位图，再取各副本与 Index K 的共同完成进度。

Main 先收齐 D 完成及 drain，再发 P free。 SR 等齐写者清理并完成全 rank 回执后，Main 才归还额度。 槽和额度继续使用逻辑容量；物理份数由注册和去重后的页描述符表达。
