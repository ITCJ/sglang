# 04: K1-05c dense 读带宽微测

**What to build:** 一个不经服务的小程序：按映射在 8 个 NUMA 各绑一段共享内存并填入同一批页的数据，GPU 进程用和 load_back 相同的拷贝接口把页 dense 读进 HBM。测 1、2、4、16 个读者压同一个段，以及 16 个读者按段交错（每段 2 个）；数据量两档（一次 4K 命中的量和它的 8 倍），每档重复 3 次取中位数，记每读者时间、总带宽、每段带宽。产出一张表和结论，回填完整记录的 U6，并给 K1-05b 的读者分配默认值一个数据依据。不阻塞任何票。细节见 k1-tickets.md 第 8 节。

**Blocked by:** None (can start immediately; 不阻塞任何票)

**Status:** ready-for-agent

**State:** open
